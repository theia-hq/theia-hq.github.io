Install Docs

Share one service with one person, and take it back.

swoosh is Theia's command-line program. You pick a service on your machine and a person. They get that one service, not your machine or your network.

The share ends on a date you pick, or sooner when you revoke it. Taking one person back leaves everyone else alone.

Your machine decides who gets in on its own; it asks no server.

A service anyone may use can be shared to anyone. A shell is shared only with a person.

Your machine serves what you name, behind one gate.

A machine serves only what you list: a shell, a folder that takes files, a local port or socket, a website fetched through it, and two diagnostics, ping and speed. Your own machines and the people you share with get in. Everyone else is refused.

Your machines are one group.

Add a machine with swoosh invite on one of yours and swoosh join on the new one. Each machine you add is me/<name>, and it reaches what your other machines serve.

swoosh finds a machine across routers and NATs.

Every machine has a key. You name a machine by its key, or by a name you gave it. swoosh connects directly when it can. When no direct path exists, a relay passes the encrypted bytes; it cannot read them or let anyone in.

One program, built from libraries that each do one job.

Each library has its own repository and works without swoosh.

swoosh
The program you install; it uses every library below.
bifrost
"Open a byte-stream to a machine identified by its public key, wherever it is on the internet, across NATs, without knowing its address." In swoosh, it dials the key.
nauthy
"Capability tokens you can revoke with no server, rooted at one ed25519 key you hold." In swoosh, it decides who gets in.
tightbeam
"A node serves named services behind one gate, addressed by its public key." In swoosh, it puts each service you name behind that gate.
services
"The general service engines: fetch, measure, sshh, and transfer." In swoosh, they are the website fetch, ping and speed, the shell, and the file drop.
keystore
"keystore stores one ed25519 secret key in one file, plain or sealed." In swoosh, it keeps each key on disk, locked with a passphrase or Touch ID.
quirk
"A QUIC-style transport over UDP, written from scratch." In swoosh, a second transport, written to learn how one works. It is not the default.

Use the libraries in your own Rust program.

Each library is a Rust crate you take from git. Its README shows the API and an example.

cargo add bifrost bifrost-iroh --git https://github.com/theia-hq/bifrost
cargo add nauthy --git https://github.com/theia-hq/nauthy --branch main
cargo add keystore --git https://github.com/theia-hq/keystore

Install swoosh

curl -fsSL https://raw.githubusercontent.com/theia-hq/swoosh/main/scripts/install.sh | sh

Prebuilt for x86_64 and aarch64 Linux and Apple Silicon macOS. The script checks the download's SHA-256 checksum before it installs.
